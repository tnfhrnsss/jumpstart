다운로드해서 바로 쓰기

요구 환경: macOS 전용 (Apple Silicon·Intel) · Java·Node 등 별도 설치 불필요 — 받아서 바로 실행됩니다.

  1. Releases 에서 최신 .dmg(또는 .zip) 받기
  2. dmg는 열어서 Jumpstart.app을 Applications로 드래그 (zip은 풀어서 옮기기)
⚠️ 코드 서명이 없어(개인용) 첫 실행 때 “확인되지 않은 개발자” 경고가 뜰 수 있습니다 → Jumpstart.app 우클릭 → 열기(최초 1회), 또는 xattr -dr com.apple.quarantine /Applications/Jumpstart.app.

소스에서 빌드하기 (개발자용)

필요 환경: macOS · Node.js 18+ (nodejs.org 또는 brew install node) 

# 1. 내려받기
git clone https://github.com/tnfhrnsss/jumpstart.git
cd jumpstart

# 2. 의존성 설치 + 앱 빌드·설치
npm install
npm run app      # → /Applications/Jumpstart.app 설치

이제 Launchpad · Spotlight · Finder에서 “Jumpstart”를 클릭해 실행하세요.

⚠️ 첫 실행 시 macOS가 “Terminal 제어 권한”을 물어봅니다 → 허용 (안 그러면 터미널 실행이 막힙니다). 다른 맥으로 .app만 복사했을 때 “확인되지 않은 개발자” 경고가 뜨면, 우클릭 → 열기 또는 xattr -dr com.apple.quarantine /Applications/Jumpstart.app.

업데이트

  2. npm run app 다시 실행 → 설치본 갱신
