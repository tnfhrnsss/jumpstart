How to use

Quick Run (Favorites)

A favorites list of items you run often. It starts empty; press the ⭐ button on any item in My Workflows · Claude Code Directories · Frequent Folders below to add it here. Remove with the ✕ next to an item.

My Workflows

  • Register a Name / Path / Command; the [Run] button opens a new terminal at that path and runs the command.
  • Leave the command empty to just open a shell at that path.
  • e.g. Name Start service · Path ~/Documents/myproject · Command npm run start

Claude Code Directories

  • Scans ~/.claude/projects/ and lists folders where you used Claude Code, most recent first.
  • Each row has [Shell] / [claude -c] / [Finder] shortcuts plus git info (repo, branch, last commit, push status).
  • Folders that were moved/deleted show "missing"; hide them with the ✕ button, and restore via "Show all" at the bottom.

Frequent Folders

Combines folders you frequently cd into in your real terminal (from shell history) with folders opened from this app, showing the most visited. Open them directly with [Shell] / [claude -c] / [Finder].

Settings (top-right ⚙)

  • Language — switch Korean / English instantly.
  • Theme — 7 themes, instant preview.
  • Terminal app — Terminal (default), iTerm2, Tabby, or Custom (kitty, WezTerm, etc. via a command template).
  • Open in — New window / New tab. New tab is supported only by Terminal & iTerm2 (see FAQ).
  • (Quick Run is populated with the ⭐ button in each list, not in settings.)

FAQ

The terminal won't open.

On first run macOS asks for permission to control Terminal → you must Allow it. If you denied it: System Settings → Privacy & Security → Automation → Jumpstart → check Terminal.

It doesn't open in a "new tab".
  • New tab works only with Terminal & iTerm2. Tabby and Custom ignore the option and open as before.
  • Terminal's new tab sends a Cmd+T keystroke, so it needs Accessibility permission on first use: System Settings → Privacy & Security → Accessibility → allow Jumpstart.
  • If no window is open, it opens a new window instead of a tab.
A folder shows as "missing".

That folder was moved or deleted (its path is still in history). Hide it with ✕ if you don't need it; restore with "Show all" at the bottom.

Where are settings / bookmarks / history stored?

Not in the project — in your user folder (~/Library/Application Support/jumpstart/) as JSON. To move to another Mac, copy those files.

How is "Frequent Folders" computed?

It replays cd entries in ~/.zsh_history in order, counts only folders that actually exist, and merges that with folders opened from this app. If there's no timestamp, the "last" time is omitted.

Is dev mode different from the installed app?

Yes. npm start is dev mode (runs while the terminal is open); the real app is /Applications/Jumpstart.app. Rebuild & reinstall to reflect code changes in the installed app.

I downloaded it on another Mac and it won't open.

It's unsigned (personal use), so Gatekeeper blocks it. Right-click → Open on Jumpstart.app (once), or run xattr -dr com.apple.quarantine /Applications/Jumpstart.app.
