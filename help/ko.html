사용 방법

빠른 실행 (즐겨찾기)

자주 쓰는 항목을 모아 한 번에 실행하는 즐겨찾기 목록입니다. 처음엔 비어 있고, 아래의 내 워크플로우 · Claude Code 디렉토리 · 자주 여는 곳 각 항목에 있는 ⭐ 버튼을 누르면 여기에 추가됩니다. 항목 옆 ✕로 제거합니다.

내 워크플로우

  • 이름 / 경로 / 명령어를 등록하면 [실행] 버튼으로 그 경로에서 새 터미널이 열리고 명령까지 실행됩니다.
  • 명령어를 비우면 그 경로에서 셸만 엽니다 (그냥 그 폴더로 빠르게 이동).
  • 예) 이름 서비스 올리기 · 경로 ~/Documents/myproject · 명령 npm run start

Claude Code 디렉토리

  • ~/.claude/projects/ 를 스캔해 Claude Code를 썼던 폴더를 최근 순으로 보여줍니다.
  • 폴더별로 [셸] / [이어가기] / [세션 선택] / [Finder] 바로가기와 git 정보(리포·브랜치·마지막 커밋·푸시 여부)를 표시합니다.
  • 이어가기는 최근 세션 이어가기(claude -c), 세션 선택은 터미널에 세션 목록이 떠서 골라 재개(claude --resume)합니다.
  • 섹션 우측 검색창으로 경로·리포명을 필터링할 수 있습니다.
  • 폴더가 이동·삭제돼 "없음"으로 뜨는 항목은 ✕ 버튼으로 목록에서 숨길 수 있고, 목록 하단 "모두 표시"로 되살립니다.

자주 여는 곳

실제 터미널에서 자주 cd 한 폴더(셸 히스토리 기반)와 이 앱으로 연 기록을 합쳐, 접근이 잦은 곳을 모아 보여줍니다. 바로 [셸] / [claude -c] / [Finder]로 열 수 있습니다.

설정 (우상단 ⚙)

  • 언어 — 한국어 / English 즉시 전환.
  • 화면 테마 — 7종, 고르면 즉시 미리보기.
  • 터미널 앱 — Terminal(기본)·iTerm2·Tabby·사용자 지정(kitty·WezTerm 등 명령 템플릿).
  • 열기 방식 — 새 창 / 새 탭. 새 탭은 Terminal·iTerm2만 지원합니다(FAQ 참고).
  • (빠른 실행은 설정이 아니라 각 목록의 ⭐ 버튼으로 추가합니다.)

섹션 접기 / 펼치기

각 섹션 제목의 ▾ / ▸ 화살표(또는 제목줄 클릭)로 섹션을 접거나 펼 수 있습니다. 접어도 개수 배지는 보이고, 접은 상태는 다음 실행에도 유지됩니다. 목록이 길 때 유용합니다.

자주 묻는 질문 (FAQ)

터미널이 안 열려요.

첫 실행 때 macOS가 "Terminal 제어 권한"을 물어봅니다 → 허용해야 합니다. 실수로 거부했다면: 시스템 설정 → 개인정보 보호 및 보안 → 자동화 → Jumpstart → Terminal 체크.

"새 탭"으로 열리지 않아요.
  • 새 탭은 Terminal·iTerm2에서만 동작합니다. Tabby·사용자 지정은 새 탭 옵션을 무시하고 기존 방식대로 엽니다.
  • Terminal(기본)의 새 탭은 Cmd+T 입력을 보내는 방식이라 첫 사용 시 "손쉬운 사용(Accessibility)" 권한이 필요합니다: 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 → Jumpstart 허용.
  • 열린 창이 하나도 없으면 새 탭 대신 새 창으로 엽니다.
목록에 폴더가 "없음"으로 떠요.

그 폴더가 이동·삭제됐다는 뜻입니다(경로는 기록에 남아 있음). 필요 없으면 ✕로 숨기세요. 잘못 숨겼다면 목록 하단 "모두 표시"로 복구됩니다.

설정·북마크·히스토리는 어디 저장되나요?

프로젝트가 아니라 사용자 폴더(~/Library/Application Support/jumpstart/)에 JSON으로 저장됩니다. 다른 맥으로 옮기려면 그 폴더의 파일을 복사하세요.

"자주 여는 곳"은 어떻게 계산되나요?

~/.zsh_history 의 cd 기록을 순서대로 따라가며 실제로 존재하는 폴더만 빈도 집계하고, 이 앱으로 연 기록과 합칩니다. 타임스탬프가 없으면 "마지막" 시각은 생략됩니다.

개발 모드와 설치된 앱이 다른가요?

네. npm start는 개발 모드(터미널 떠 있는 동안만)이고, 실제 사용은 /Applications/Jumpstart.app 입니다. 코드 변경을 설치본에 반영하려면 다시 빌드·설치해야 합니다.

다른 맥에서 받았더니 안 열려요.

코드 서명이 없어(개인용) Gatekeeper가 막는 것입니다. Jumpstart.app을 우클릭 → 열기(최초 1회), 또는 터미널에서 xattr -dr com.apple.quarantine /Applications/Jumpstart.app.

더 궁금한 점·버그는 GitHub Issues로 남겨 주세요.
